# v0.4 三轮代码审查与验收

审查日期：2026-10-12。基准为[语法与功能设计](solution-and-implementation.md)。以下为三轮不同关注点的自审及回归，不是三位独立审查者。

## 第一轮：语法、作用域与数据契约

逐项核对原页快照、当前页 block、独立 foreach、混合成员、中文图片后缀、内层段落循环、缺失值和简写列定义。

| 发现/风险 | 修复与验证 |
|---|---|
| 旧单页/单类分页器无法处理多模板页混合组 | 用 PagePlan 与统一 flow_renderer 替代，原页和续页顺序测试 |
| 旧规则会因空表/坏图删除整个组，或重复标题 | 改为仅删除对应成员；标题只输出一次，40 行长表后接并排图测试 |
| 表格内层字段与兼容直接 rows 发生优先级混淆 | 明确字段对象/数组优先；兼容旧直接表项的 metadata 名称 |
| 插值跨 run 或 SQL 值含模板标签会丢样式/被再次解析 | 每个值使用第一个 `{` 的源样式，只编译原模板一次 |
| foreach 被误当行内循环，或接收基本类型数组 | 只允许整段对象数组，禁止第三层；明确 TemplateError |
| 表格选择器拼接会静默退回当前对象 | 有括号的选择器必须是单个完整表达式；非法形式预检失败 |

## 第二轮：布局、样式与端到端数据

生成真实三页模板副本并渲染所有输出页，检查标题、母版、长表数据、内部表数组、图片并排和后续原页的位置。

| 发现/风险 | 修复与验证 |
|---|---|
| 占位文字复制到不同空白布局后继承了灰色/居中样式 | 复制前实体化原母版/布局/Shape 的有效文字样式；28pt、粗体、项目符号及段落属性跨页测试 |
| 原表格段落属性复制不完整 | 完整复制 pPr，包括行距、缩进与段落属性 |
| 非关系属性内的 rId 文本被误改 | 只重映射关系命名空间内的属性 |
| 相邻图片在表格增高后可能单独分页 | 模板横排组成 band，完整横排不足时一起续页；相对 Y 偏移测试 |
| 多原页相同 block 被错误合并 | 每个原页独立计划；同名 block 跨页样式与位置测试 |

## 第三轮：生产边界、异常保护与性能

检查有界读取、资源累计、并发请求隔离、异常写入及样式节点合法性，执行负载回归。

| 发现/风险 | 修复与验证 |
|---|---|
| 图片检查后重新读取，可得到不同文件或不兼容编码 | 缓存验证后的字节；EXIF 方向和 WEBP 规范化测试 |
| 模板包解压膨胀/部件过多、检查后文件被更换 | 有界一次读取，限制压缩与解压大小、部件数，检查和加载同一份字节 |
| 重复表头/首列使生成单元格超过输入限制 | 分别累计输入与输出单元格，超限在原子保存前失败 |
| 静态页码、日期字段被重建为普通文本 | 无语法段落按原节点保留，字段节点逐字 XML 回归 |
| 截断后的超长 block 名称导致输出重名 | 唯一后缀加入源页和源 Shape ID，长 block 名称冲突测试 |
| 样式继承合并留下互斥节点，或字体/填充顺序不合法 | 合并时替换互斥属性并按 schema 顺序排列；专门回归 |
| 非有限数字、过大格式精度、非整数首列数 | 有限值/类型/格式宽度预检，不允许隐式截断浮点数 |
| 生成失败破坏已有目标或留下临时文件 | 资源失败与模拟 disk-full 两类测试，已有目标保持原样 |
| 请求间上下文或图片缓存共享 | 缓存/预算均请求内；4 线程、8 请求隔离测试 |
| 文本每次插值扫描全体 run，长文本性能退化 | 源样式跨度二分定位，减少重复全量扫描 |

## 最终验证结果

- 92 项自动化测试通过；含真实模板端到端自动断言。测试数量不等于 100% 代码行覆盖率。
- Ruff 静态检查、格式检查、Python 编译和 git diff 空白检查通过。
- `tests/fixtures/test-multipage.pptx` 是用户三页 test.pptx 的语法调整副本；未覆盖用户原件。
- `output/multipage-demo/generated.pptx`：6 页，7 张可编辑原生表格，31 行数据，4 张动态图片。
- ID 1–25 顺序完整、无遗漏/重复；三个原页保持 CPS → CNS → Cns overall 顺序。
- 长表续页重复表头；表格结束后才输出图；第二组标题保留原样式；空成员不影响其他成员。
- PPTX 包结构检查 finding_count=0；几何检查 finding_count=0、warning_count=0；全部 6 页渲染并逐页检查。
- 较大规模回归：20 张逻辑表、2,000 行数据，生成 162 页、160 张表片段；完整计数通过。当前本机生成加重载检查约 1.60 秒，文件 597,262 字节；这是单次样本，不是生产 SLA 或并发压力测试。

## 结论与剩余边界

本轮发现的问题均已修复并回归；在已确认功能和上述测试范围内，没有遗留已知阻断级缺陷。无法通过三轮审查证明任何软件绝对没有生产 bug。

- 字体高度属于估算；用户安装的字体、PowerPoint 与当前渲染器可能不同。没有执行原生 PowerPoint 客户端验收。
- 单行表格数据/单个文本段落超过完整续页区域会明确报错，不拆断数据行或段落。
- 固定普通元素不自动避让，多个 block 不自动重新规划任意静态介绍内容。
- `python-pptx` 的克隆能力有限；少量私有接口及 XML 样式复制集中在兼容/渲染模块，依赖升级需完整回归。
- HTTP 层仍需受控路径、请求体/并发/任务超时和唯一输出路径；不同请求写同一目标文件不是库解决的业务竞态。
