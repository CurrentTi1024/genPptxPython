# v0.4 实现计划

需求契约：[完整语法与功能设计](solution-and-implementation.md)。

1. 指令与数据：增加 page、中文尺寸后缀、简写列定义和第一行推导；统一缺失值与累计资源限制。
2. 文本处理：先编译插值/if/段落 foreach，保留第一个左花括号的 run 样式及段落属性，禁止语法二次解释。
3. 页级计划：记录原始页快照，按页编译独立及显式 block，取消单表单页和混合组限制。
4. 统一布局：成员横排、内部表格/图片数组、独立文本循环、整组保持和成员续页；使用同母版空白续页。
5. 入口与兼容清理：一次加载/一次原子输出，移除旧独立分页器，更新 CLI 和专题文档。
6. 自动化与端到端：新增需求测试，更新被新需求替代的旧断言；从用户模板制作测试副本，生成并渲染最终 PPTX。
7. 三轮审查：第一轮核对语法与需求；第二轮核对布局、页序和数据完整性；第三轮检查资源限制、失败保护及性能。每轮记录问题、修复和回归证据。
8. 交付：测试通过后提交相关源码、文档和测试副本，保留用户原件与 Office 锁文件，推送 origin/main 并验证远程提交。
