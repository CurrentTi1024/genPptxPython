# 当前需求总览（v0.4）

唯一详细契约见[完整语法与功能设计](solution-and-implementation.md)，执行过程见[实现计划](implementation-plan.md)，验证证据见[三轮代码审查](code-review.md)。本页替代早期单页表格方案，避免旧约束与当前实现冲突。

## 目标

继续使用 Python/python-pptx，以用户制作的 PPTX 决定企业视觉样式。Dify 查询、计算并输出 data；服务根据 Shape 类型及模板语法生成可编辑的 PPTX，不要求 Dify 输出 id、title 或 tableName。

## 已确认范围

- 所有原始页各自作为模板页，静态页保留，续页紧跟原页。
- `item` 指向 data 字段；显式同页相同 `item + block` 关联混合组；没有 block 就独立。
- 组内标题、多个表格、图片及图片数组一起流式布局，默认尽量同页多组，`page=group` 每项新页。
- 长表拆页重复表头，不重复组标题或原页普通标题，不加“续”。续页使用同母版空白布局。
- 元素缺失/为空只删除该元素；全部循环为空仍保留原页固定内容。
- 文本内容支持插值、行内 if、对象数组的整段 foreach；每个 value 继承第一个 `{` 的完整样式。文本 Shape 名称内容不插值。
- 内部 foreach 不再嵌套，不支持第三层。文本 Shape foreach 仅纵向排列。
- 表格 rows 固定，columns 可省略按第一行推导；单表对象或表格数组均支持；表格自动增删行列。
- 保留行高、列宽、拆列、格式化、空值、溢出策略。动态原型不支持合并单元格。
- 图片单路径/数组、可选 rows/cols、x/y/xy，兼容中文括号与逗号。无效图片隐藏。
- 模板相对横排保留；增高推动下方元素，删除后收拢。整排图片放不下整体续页。
- 统一入口、跨页累计资源上限、独立请求缓存、生成名唯一、原子输出和失败保护。

## 边界

固定普通 Shape 不参与自动避让；动态区域需由模板作者预留。字体测量为估算，模板/字体/依赖更新需真实渲染回归。v0.5 新增 FastAPI 服务及两参数 generate_ppt 入口，协议见[HTTP 说明](entry-routing.md)；不下载网络图片，不执行 Python 表达式或 SQL。
