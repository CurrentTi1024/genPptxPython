# PPT 模板语法与功能设计（v0.4）

本文是当前实现的需求契约。适用于单次生成入口 `generate_presentation(template_path, data, output_path, config=...)`。SQL 与业务计算仍由 Dify 完成。

## 1. 页面与循环作用域

- 按原 PPTX 页序处理所有原始页，不需要额外标记模板页。
- 每页的循环结果和续页紧跟该原页，之后才处理下一原页；生成页不参与第二次扫描。
- 普通页保留，处理其普通文字和单图片。
- 同页相同 `item + block` 组成逻辑组。未填写 block 的 Shape 各自独立，不因 item 相同而关联。
- block 不跨页关联，同名 block 可在其他页使用不同模板样式。
- 根字段缺失、null 或空数组视为空循环：删除占位元素，但保留原页固定元素。
- 组内不存在的成员只删除该成员，其他成员继续显示。

## 2. Shape 名称语法

```text
<foreach item=数组路径 block=自定义组名 page=group>内容</foreach>
```

`item` 必填，支持点路径；`block` 可选；`page` 可选，默认 flow（尽量同页），group 表示每个外层数据项新起一页。首个数据项使用原页，空项不产生额外页。参数在组内必须一致，可只声明在一个成员上。

| Shape | 内容含义 |
|---|---|
| 文本 | 普通名称，完全不解析中间表达式 |
| table | `{{table1}}` 选择当前项的表格字段，空或普通名称兼容直接 columns/rows 表项 |
| 图片 | `{{images}}` 选择当前项图片字段；空内容读取当前项本身的路径 |

表格和图片选择器必须是完整的单个 `{{字段路径}}`，不能混入路径拼接或执行表达式。文字、表格、图片可在同一组中混排，组内允许多份表格和多个图片数组。

图片可额外填写正整数 `rows`、`cols`，两者独立可选。文字不支持网格参数。支持 `(x)`、`(y)`、`(x,y)`，以及中文括号、中文逗号或混合写法 `（x，y）`。默认 x。

## 3. 文本内容语法

普通文本无需 Shape 名称，取值来自根 data。组内文本取值来自当前外层对象。显式文本 Shape foreach 每项复制整个框，默认纵向排列。

### 插值

```text
分类：{{title}} — {{status}}
```

缺失或 null 清除占位符，保留固定文字。每个替换值继承第一个 `{` 所在 run 的完整样式，占位符跨 run 时也一样；前后文字样式不变。动态数据不再被二次解析为语法。

### 条件

```text
设备：{{title}}<if status>，状态：{{status}}</if>
```

缺失、null、false、0、空字符串、空数组和空对象为假。支持行内条件，不执行 Python 表达式。完全为空的条件段落删除。

### 段落循环

```text
<foreach items=details>说明：{{description}}</foreach>
```

foreach 必须包住整个 PowerPoint 段落（Enter，不是软换行）；数组仅支持对象。逐项复制段落，保留项目符号、缩进、行距、各 run 样式。内部插值和 if 从当前内部对象读取。空数组删除该段落。禁止嵌套内部 foreach，不支持第三层循环。

普通文本、组文本和静态表格单元格使用同一文本处理器。文本框无任何可见文字时删除；有固定文字则保留。动态文字按内容估算高度，超长内容按段落续页，不拆断单个无法容纳的段落，后者明确报错。

## 4. 表格数据

```json
{
  "tables": [{
    "title": "设备分类",
    "table1": {
      "columns": [{"loc": "区域"}, {"count": "数量"}],
      "rows": [{"loc": "华中", "count": 12}]
    },
    "table2": [{"rows": [{"price": 3000, "amount": 6000}]}],
    "images": ["/data/a.png", "/data/b.png"]
  }]
}
```

- 仅使用 rows，不支持 raws 别名。
- 表格字段可为单对象或对象数组。缺失/null/空对象/rows 缺失或为空时隐藏。
- columns 可省略，按第一条对象行的字段顺序推导列名；不扫描后续行补列。
- 显式 columns 支持字符串列（兼容矩阵行）和单键映射 `{字段:显示名称}`，不支持 key/label 定义。
- 对象行按字段取值，矩阵行数量必须与 columns 匹配。
- 模板行列随数据增删；表头、数据行、字体和单元格样式继承原型，结果为可编辑 table。
- 保留 `_table` 的 template/content/equal 列宽、最小列宽、重复前导列、wrap/shrink/truncate/error、最小字号和空值选项。
- 数字日期格式通过 `_table.formats={字段:格式}` 配置，列空值通过 `_table.nullValues={字段:文本}` 配置，使简写列定义仍能使用原格式化能力。
- 动态原型禁止合并单元格。非有限数字、非法格式及资源超限明确报错。

## 5. 图片与内部网格

- 路径为空、文件不存在、损坏、越界读取或超过单图片限制时删除该图片，不删除同组标题和表格。
- 图片支持单路径、路径数组，根图片循环也支持对象数组加字段选择器。
- x 保持模板宽度，y 保持模板高度，x,y 使用模板宽高；网格整体缩小时对结果尺寸统一缩放。
- rows/cols 都不设置时根据原型及可用区域计算；只设置一维时另一维自动计算；都设置时使用指定网格。填充顺序按行优先。
- 两张独立图片在模板同一横排时保持相对横向位置，一排放不下则整体换页；单张坏图隐藏后其他图片继续显示。
- 循环原型不支持旋转，普通单图片保留原旋转。只支持服务器本地栅格文件。

## 6. 排版与分页

- 模板成员按纵坐标排序；垂直区域重叠且水平方向不相交的成员视为同一横排。
- 相邻横排间距取模板间距。元素增高推动下方元素；整排删除后收拢其空间。
- 完整下一组在当前页能放下则留在当前页，否则整组新页开始。超出完整新页的组按成员续页。
- 长表按数据行拆页，每页重复表头。组标题只输出一次，不自动添加续字；表格结束才处理后方图片。
- 续页选择原页同一母版的空白布局，清除自动占位符，不复制原页普通 Shape。保留母版样式，从统一顶部边距开始，底部保留页脚。
- 多个独立 block 在原页使用各自区域；续页只生成正在延续的 block，各续页保持连续。
- Shape 生成名称附加源页、源 Shape ID、block、项和片段标识；全文件生成名称唯一。
- minimum_fragment_rows 默认 2：长表尽量避免在余下空间只放极少行；完整新页只能放一行时允许一行，避免无法推进。

## 7. 入口与生产边界

入口一次加载 PPTX，先编译全部原页和校验语法，再处理静态内容并逐页展开。输出写入同目录临时文件，成功后原子替换，失败保留已有目标。

配置包括续页顶部/底部边距、组间距、最大页数、表数、单元格数、图片数/字节/像素、循环项数、文本长度和生成段落数。所有计数跨整个 PPTX 累计，不按模板页重置。输入和输出单元格均受限，后者包含分页重复表头和拆列重复首列。模板限制压缩大小、解压总大小及部件数量；一次有界读取后在内存检查与加载，避免检查后再读文件产生竞态。图片按规范绝对路径缓存已验证的字节；HTTP 服务配置 allowed_image_roots。

没有语法的静态段落保持原始节点，保留日期、页码字段等。原型占位文字的母版/布局有效样式在复制前实体化，续页不因切换布局而改变字体、颜色、项目符号和段落属性。

固定文字不自动移动，模板作者应把固定介绍与动态区域分开。行高和文字高度属于字体估算，模板修改后需要真实渲染验证；不承诺不同渲染器像素一致。

## 8. 验收

必须覆盖多模板页页序、空页保留、跨页 block 隔离、独立 foreach、混合组、多表/多图、段落 if/foreach、首括号样式、整体换页、长表后接图片、母版空白续页、中文后缀、资源累计和原子失败保护。

以用户 test.pptx 为来源生成测试副本，不修改用户原件。端到端检查数据完整、PPTX 部件关系、原生表格可编辑性、生成名称唯一、几何边界及所有页渲染。
