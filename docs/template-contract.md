# 模板制作协议（v0.4）

完整定义以[语法与功能设计](solution-and-implementation.md)为准。

1. 制作所有所需页面，包括固定介绍页和多个循环页。页面顺序就是输出顺序。
2. 普通文本直接写 {{变量}}、<if 变量>...</if> 或整段 <foreach items=数组>...</foreach>。
3. 单图片在 Shape 名称填写 {{路径变量}} 和可选尺寸后缀。
4. 循环 Shape 在名称填写 <foreach item=数组 block=组名>...</foreach>。
5. 同页相同 item + block 关联；不写 block 则各自独立，不跨页关联。
6. 组文本在实际文本内容取当前外层对象字段，名称中间只是普通名称。
7. 表格或图片可用 {{字段}} 选择当前外层对象内的数据；字段可以是单值或数组。
8. 模板上下位置控制输出顺序，横排控制并排关系。动态元素增加高度时下方成员下移，删除后补位。
9. 图片 rows/cols 可选，文字不支持网格。page=group 可让每个外层项新起一页。
10. 续页使用同母版空白布局，不复制原页普通 Shape；模板布局中的非占位企业装饰仍可能继承，需放在受控母版/空白布局中。

每个插值的字体、字号、颜色、粗体、斜体等来自第一个左花括号。模板保存时应检查占位符跨 run 的样式。

不支持动态合并单元格、旋转循环原型、物理组合子元素上的 foreach 和第三层循环。错误语法会明确失败。
